# terraform-template
This file is written as a template explanation, but please replace the contents with a normal README.md after implementation.

Please replace the curly bracket in each file as appropriate.

- 01_main.tf
  Define terraform, provider
- 02_variable.tf
  Define variables, locals
- 03_datasource.tf
  Define Data Source
- XX_resource_set.tf
  Define a set of resources.
  For example, 11_lambda.tf contains aws_lambda_function, aws_lambda_function_url, aws_lambda_permission, etc.
- 99_output.tf
  Define Output
